# Fivestars

> Fivestars was a customer loyalty, rewards and marketing platform for small and
> mid-sized brick-and-mortar merchants in North America, founded in 2010 in San
> Francisco and acquired by SumUp in 2021. Its product is now sold as SumUp
> Connect (SumUp Loyalty). Fivestars-branded surfaces are still live, but the
> company publishes no public API, no developer portal and no machine-readable
> contract.

This file was generated by API Evangelist from the public Fivestars surface. It
is not published by Fivestars. Source of record:
https://github.com/api-evangelist/fivestars

## API status

- **No public API.** There is no OpenAPI, Swagger, GraphQL SDL, AsyncAPI,
  Postman collection or MCP server published on any Fivestars-controlled host.
- `api.fivestars.com` resolves but returns HTTP 404 on `/openapi.json`,
  `/openapi.yaml`, `/swagger.json`, `/v1/openapi.json`, `/api-docs`, `/docs`,
  `/redoc` and every `/.well-known/` path.
- `developers.fivestars.com` and `docs.fivestars.com` do not resolve in DNS, and
  the Wayback Machine holds no capture of either.
- Agents should not attempt to call a Fivestars API. There is nothing to call.

## Live company surfaces

- [Fivestars marketing site](https://fsweb.fivestars.com/): product overview for
  the loyalty, rewards and payments platform.
- [SumUp Connect](https://fsweb.fivestars.com/sumup-connect/): the successor
  product page on a Fivestars host.
- [Merchant dashboard](https://dashboard.fivestars.com/): merchant login. Single
  page app; `rmd.fivestars.com` 308s here.
- [Help center](https://help.fivestars.com/): merchant support articles.
- [Status page](https://status.fivestars.com/): Atlassian Statuspage. Machine
  readable at `/api/v2/summary.json`, `/api/v2/status.json` and `/history.rss`.
  Tracks the Twilio messaging dependencies behind merchant SMS campaigns only.
- [Terms of Service](https://fsweb.fivestars.com/legal/): effective 2023-01-01.
- [Privacy Policy](https://fsweb.fivestars.com/privacy/)
- [GitHub organization](https://github.com/fivestars): 30 public repositories,
  mostly forks plus Terminal API tooling.

## Client libraries

- **TapiSDK** (Swift/iOS, v0.0.6, released 2024-05-16) —
  https://github.com/fivestars/tapi-sdk-ios-distribution — a wrapper around the
  Terminal API for payment processing "for legacy Fivestars integrators
  including loyalty with cPay". Distributed by Swift Package Manager and
  CocoaPods from the company's GitHub org; not on a public package registry.
- `tslint-config-fivestars` (npm, 0.5.1, 2019-06-21) and
  `eslint-config-fivestars` (npm, 1.2.4, 2018-07-26) are first-party linter
  style configs, not API clients.
